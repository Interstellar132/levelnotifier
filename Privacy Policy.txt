Privacy Policy

Level Notifier is a Discord bot designed to capture your Geometry Dash levels, and announce when your new uploads. This bot is developed by Interstellar, who you can contact via Discord or Support Server listed in Level Notifier's bio.

Level Notifier collects information such as your Server ID, Role IDs, Channel IDs, Channel Names, Geometry Dash Account ID, Geometry Dash Player ID, recent levels you've uploaded on your Geometry Dash account (excluding unlisted levels). This data is collected through slash command ran by a server admin, where your Account and Player IDs are stored securely, as well as your most recent level ID. Any other older levels on your account are discarded immediately after checked. As for the server owner, setting up the Level Notifier bot stores the Channel Name and Channel ID you have chosen, and the Role ID you have chosen, if you did choose one, as well as your Server ID. The bot cannot function without the server ID, Channel Name, and Channel ID. Level Notifier also uses the Message Content Intent, Server Members Intent, and Presence Intent, however does not store any of this data anywhere.

This data collection is needed for providing Level Notifier's core functionality. In order for Level Notifier to work, it will need your Server ID, your chosen Channel Name and Channel ID, the Account ID and Player ID of the users you add, and their recent Level IDs.

By adding Level Notifier to your Discord server, you agree to the terms of this Privacy Policy and interact with Level Notifier voluntarily. Level Notifier does NOT collect any other data that is not mentioned in this Privacy Policy.

Level Notifier stores the data in US West servers with Amazon Web Service, and securely stays in rest where the Level Notifier's developer, and the hosting provider has access to.

Upon removing a Geometry Dash account Level Notifier watches, any information associated with the Account and Player IDs are immediately deleted. However, upon removing the bot from your server, the data is retained and must be requested for deletion by contacting the Level Notifier developer via Support Server or directly to the developer's Direct Messages on Discord, X, or Instagram and must provide the Server ID.

The Level Notifier's database runs through Amazon Web Services (AWS), which is the only Third-Party that has access to the data Level Notifier collects.

You, the user, has a right to request any data Level Notifier has on you, as well as deletion of your data. If you want to opt out, you would have to do so by contacting the server owner or admin and requesting they remove your data. If the server owner or admin refuse to do so, you can go as far as to contact the Level Notifier developer via Support Server and request deletion from there. You will need to provide the Server ID of the server you're trying to opt out of.

Level Notifier should NOT be used for users under the age of 13, and for any reason a server owner, server admin, or Level Notifier's developer become aware of an underage user, any data on them MUST be deleted immediately, or as soon as possible. Failure to do so will prompt the developer to remove any and all data Level Notifier has on the discord server.

Any changes to this Privacy Policy will be announced in the Support Server listed in Level Notifier's bio.
